# Pull Request Template

Thank you for contributing to the **VMware Virtualization Optimization Toolkit**!  
Please use this template to describe your changes clearly and ensure they meet project standards.

---

## 📖 Description

- What does this PR do?
- Why is it needed?
- Which scripts, docs, or diagrams are affected?

---

## 🧪 Testing

- How did you test your changes?
- Provide sample outputs, screenshots, or logs if applicable.
- Confirm that scripts run successfully in a VMware vSphere environment.

---

## ✅ Checklist

Before submitting, please confirm:

- [ ] Code follows PowerShell best practices (naming conventions, comments, parameter validation).
- [ ] Documentation (`/docs`) updated if new features or scripts were added.
- [ ] README.md updated if necessary.
- [ ] Diagrams (`/diagrams`) updated if architecture changed.
- [ ] No sensitive data (passwords, tokens) included in scripts.
- [ ] Changes align with the GNU GPL v3 license.

---

## 📬 Additional Notes

- Link related issues (e.g., `Fixes #12`).
- Mention reviewers if specific expertise is required.
- Provide context for any breaking changes.
